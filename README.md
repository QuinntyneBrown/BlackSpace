# Black Space Canada

A community platform for Black Canadian engineers, scientists, and technologists building Canada's space and defence systems.

**Website:** [blackspace.ca](https://blackspace.ca)

## Tech Stack

- **Frontend:** Angular 21, TypeScript 5.9
- **Testing:** Vitest
- **Package Manager:** npm

## Project Structure

```
docs/specs/       # Design and requirements specifications
src/BlackSpace.Web/  # Angular application
```

## Getting Started

```bash
cd src/BlackSpace.Web
npm install
npm start
```

The dev server runs at `http://localhost:4200/`.

## Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Start dev server |
| `npm run build` | Production build |
| `npm run watch` | Build in watch mode |
| `npm test` | Run tests |
